# sistemaGYM · Demo web

Esta es una adaptación web interactiva de sistemaGYM preparada para GitHub Pages. Funciona sin servidor, sin base de datos y sin cuentas reales. Incluye socios, asistencia, inventario y ventas con datos ficticios; los cambios se guardan solo en el navegador que abre la demo.

**Demo en vivo:** https://fernando-rtx.github.io/sistemaGYM/

La rama `demo-github-pages` contiene únicamente esta demo estática. No usa Supabase ni se conecta al sistema de producción.

Para ajustar la publicación, abre **Settings → Pages** y selecciona **Deploy from a branch → `demo-github-pages` → `/(root)`**.
