# sistemaGYM

Sistema de gestión para gimnasio con panel operativo, socios, asistencia, ventas e inventario.

## Demo web

**[Abrir demo interactiva en GitHub Pages](https://fernando-rtx.github.io/sistemaGYM/)**

La demo se publica desde la rama [`demo-github-pages`](https://github.com/Fernando-rtx/sistemaGYM/tree/demo-github-pages). Es una adaptación estática con datos ficticios que se guardan en el navegador. No requiere cuenta, servidor ni base de datos, y no se conecta a Supabase.

## Proyecto

El código de la aplicación original está en `src/`. La configuración de Supabase para desarrollo se proporciona mediante variables de entorno locales; no guardes claves privadas en el repositorio.
